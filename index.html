📖 사용 방법
1
클래스 추가 & 예시 문장 입력
상단 + 클래스 추가 버튼으로 카테고리를 만들고, 각 클래스 박스에 예시 문장을 한 줄에 하나씩 입력합니다. 클래스당 최소 5개 이상 입력할수록 정확도가 높아집니다.
2
학습 파라미터 설정 후 학습 시작
Epochs(반복 횟수, 기본 60), Hidden Units(모델 크기, 기본 64), Learning Rate(학습 속도, 기본 0.001)를 조정하고 ▶ 학습 시작을 누릅니다. 진행 바에서 Loss와 Accuracy를 실시간으로 확인할 수 있습니다.
3
예측 테스트
학습 완료 후 예측 패널에 문장을 입력하고 분석 버튼을 누르면 각 클래스의 확률을 시각적으로 확인할 수 있습니다.
4
모델 내보내기 & 재사용
모델 저장 & 불러오기 패널에서 .mollar 파일을 다운로드합니다. 다음에 이 페이지에 파일 하나만 올리면 재학습 없이 바로 예측을 재개할 수 있습니다. 위 활용 예제처럼 외부 프로젝트에서도 사용 가능합니다.

📦 모델 내보내기 .mollar 단일 파일
가중치와 클래스 정보를 .mollar 파일 하나로 다운로드합니다. 나중에 이 페이지에 파일 하나만 올리면 바로 예측을 재개할 수 있습니다.
📂 모델 불러오기
내보낸 .mollar 파일을 선택하면 바로 예측을 재개할 수 있습니다. 클래스 이름과 학습 데이터도 자동으로 복원됩니다.
📦 학습 완료 모델 다운로드 & 활용 예제
학습이 끝나면 .mollar 파일 하나를 다운로드해 아래 예제처럼 어디서든 바로 사용할 수 있습니다.
예제 1 — HTML에서 바로 불러와 예측
<!-- ① TF.js 및 Transformers.js 로드 --> <script src="https://cdn.jsdelivr.net/npm/@tensorflow/tfjs@4.15.0/dist/tf.min.js"></script> <!-- ② 모델 파일을 같은 폴더에 두고 로드 --> const model = await tf.loadLayersModel('model.json'); // ③ 텍스트 임베딩 (Transformers.js 필요) import { pipeline } from '@xenova/transformers'; const extractor = await pipeline('feature-extraction', 'Xenova/multilingual-e5-small'); async function predict(text) { const out = await extractor([`query: ${text}`], { pooling: 'mean', normalize: true }); const tensor = tf.tensor2d([Array.from(out.data)]); const probs = Array.from(model.predict(tensor).dataSync()); return probs.indexOf(Math.max(...probs)); // 가장 높은 클래스 인덱스 }
예제 2 — Node.js 서버에서 사용
// npm install @tensorflow/tfjs-node @xenova/transformers const tf = require('@tensorflow/tfjs-node'); const { pipeline } = await import('@xenova/transformers'); const model = await tf.loadLayersModel('file://./model.json'); const extractor = await pipeline('feature-extraction', 'Xenova/multilingual-e5-small'); const labels = ['인사', '음식']; // model.json 의 userDefinedMetadata.labels 에서 읽어도 됩니다 async function classify(text) { const out = await extractor([`query: ${text}`], { pooling: 'mean', normalize: true }); const probs = Array.from(model.predict(tf.tensor2d([Array.from(out.data)])).dataSync()); const idx = probs.indexOf(Math.max(...probs)); return { label: labels[idx], confidence: probs[idx].toFixed(4) }; } console.log(await classify('안녕하세요')); // { label: '인사', confidence: '0.9742' }
예제 3 — 완성된 HTML 파일 (복붙 후 바로 사용)
<!-- model.mollar 파일과 같은 폴더에 저장하세요 --> <!DOCTYPE html> <html lang="ko"> <head> <meta charset="UTF-8"> <title>mollar 예측기</title> <script src="https://cdn.jsdelivr.net/npm/@tensorflow/tfjs@4.15.0/dist/tf.min.js"></script> </head> <body> <input id="inp" placeholder="문장을 입력하세요" style="width:300px;padding:8px"> <button onclick="run()">예측</button> <script type="module"> import { pipeline } from 'https://cdn.jsdelivr.net/npm/@xenova/transformers@2.17.2/dist/transformers.min.js'; // ① .mollar 파일 로드 const mollar = await fetch('model.mollar').then(r => r.json()); const labels = mollar.userDefinedMetadata.labels; // base64 weights → ArrayBuffer const binStr = atob(mollar.weightDataBase64); const binBuf = new Uint8Array(binStr.length); for (let i = 0; i < binStr.length; i++) binBuf[i] = binStr.charCodeAt(i); const model = await tf.loadLayersModel(tf.io.fromMemory({ modelTopology: mollar.modelTopology, weightSpecs: mollar.weightsManifest[0].weights, weightData: binBuf.buffer })); // ② 임베딩 모델 로드 const extractor = await pipeline('feature-extraction', 'Xenova/multilingual-e5-small'); // ③ 예측 함수 async function predict(text) { const out = await extractor([`query: ${text}`], { pooling: 'mean', normalize: true }); const probs = Array.from(model.predict(tf.tensor2d([Array.from(out.data)])).dataSync()); const idx = probs.indexOf(Math.max(...probs)); return { label: labels[idx], confidence: probs[idx].toFixed(4), scores: Object.fromEntries(labels.map((l,i) => [l, probs[i].toFixed(4)])) }; } // ④ 버튼 연결 window.run = async () => { const text = document.getElementById('inp').value.trim(); if (!text) return; const result = await predict(text); console.log(result); // { label: '인사', confidence: '0.97', scores: {...} } }; </script> </body> </html>
